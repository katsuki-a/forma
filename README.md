# forma

**データのかたちを定義し、チームで使うアプリに。**

forma は、ユーザーがコードを書かずにデータ項目（スキーマ）を定義し、複数のユーザーで共有する業務アプリを作るためのソフトウェアです。

## プロジェクトの状態

現在は仕様策定段階です。ドキュメント運用と検査用ツールを整備しています。アプリ本体は未実装で、利用可能なサービスやデモはまだありません。

## 開発への参加

Node.js 22.14以上の22系とnpmを使用します。現在の検査対象はドキュメントと検査ツールです。

```sh
npm ci
npm run check
```

`check` はTypeScriptの型検査、公開ドキュメントの構造検査、検査ツールのテストを実行します。CIでも同じコマンドを使い、非公開資料なしで実行できます。

管理者はローカルの `docs/` を用意した環境で `npm run check:local` を実行し、仕様の根拠が承認済みの意図かを照合します。公開CIの成功は、この承認照合の成功を意味しません。

変更を始める前に [AGENTS.md](AGENTS.md) と [現行仕様](spec/0001-product-core.md) を確認してください。
