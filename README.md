# forma

**情報にかたちを。家族と、仲間と。**

forma は、ユーザーがコードを書かずにデータ項目（スキーマ）を定義し、家族や仲間と共有するアプリを作るための情報共有ソフトウェアです。暮らしの記録から仕事の情報まで、自分たちに合ったかたちで整理できます。

## プロジェクトの状態

現在は仕様策定段階です。初期の機能範囲、ドキュメント運用、デザインシステムを定義しています。アプリ本体は未実装です。ローカルでデザインシステムの画面見本を確認できます。

## ローカルで画面を確認する

```sh
npm ci
npm run dev
```

ブラウザーで http://127.0.0.1:3000/ を開きます。トップページには共通部品を使う画面見本が表示されます。入力と状態表示を試せますが、情報の保存や共有は未実装です。停止するにはターミナルで Ctrl+C を押します。

## 開発への参加

Node.js 22.14以上の22系とnpmを使用します。現在の検査対象はドキュメントと検査ツールです。

```sh
npm ci
npm run check
```

`check` はTypeScriptの型検査、公開ドキュメントの構造検査、検査ツールのテストを実行します。CIでも同じコマンドを使い、非公開資料なしで実行できます。

管理者はローカルの `docs/` を用意した環境で `npm run check:local` を実行し、仕様の根拠が承認済みの意図かを照合します。公開CIの成功は、この承認照合の成功を意味しません。

変更を始める前に [AGENTS.md](AGENTS.md) と [現行仕様](spec/0001-product-core.md) を確認してください。
