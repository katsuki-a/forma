# アプリ作成の拡張性

## FRM-030: 対話による作成を共通の定義・検証へ接続できる

対話によるアプリ作成を将来のコア機能として追加できるよう、アプリ定義とその検証を手動の編集画面や特定の生成サービスから独立させる。生成された定義も、手動で作成した定義と同じ形式・検証・反映の経路を利用する。

根拠: INT-003, INT-004

確認条件: 将来の生成処理を模した定義を、手動編集と同じ検証とプレビューへ渡せる設計である。作成元によって定義の受理条件が変わらず、生成サービスを追加しても保存済みアプリと手動編集を作り直す必要がない。初期版でのAI提供を意味しない。
