# デザインの契約

## FRM-020: 木をモチーフとする視覚言語

データの親子関係を読み取れる構造と、明るすぎない深緑を基調とする。家族で使える親しみやすさ、仕事にも使える信頼性と知性を両立する。

根拠: INT-003

確認条件: 現在の位置と親子関係を見分けられ、主要な操作と構造に深緑が一貫して使われる。家庭と仕事の両方の具体例で、用語と操作の分かりやすさをレビューする。

## FRM-021: 共通のデザイン定義からUIを再現する

UIは版管理するトークン、共通部品、レイアウト・状態の規則から作成する。画面を追加するたびに独立した配色や部品を生成しない。

根拠: INT-003

確認条件: 同じ役割・状態のUIが同じトークンと部品を参照する。新規画面を追加しても既存画面の視覚言語が変わらない。現在の具体的な定義は [デザインシステム](../design/README.md) とその参照ファイルを使う。
